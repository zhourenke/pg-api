# Issue Policy — pg-api fork

This repository is a downstream modification fork of [new-api](https://github.com/QuantumNous/new-api). It does not file or accept issues, neither in this repository's tracker nor against the upstream project.

When you find a defect, an upstream limitation, or a design conflict while working here:

- Fix it in this repository, or report it to the owner in the task summary.
- Do not create an issue anywhere, and do not draft an upstream issue body.
- Do not reuse the upstream agent issue template that previously filled this file.

Reading upstream code, documentation, issues, and releases is allowed and encouraged, as context only. Upstream defects that this fork does not need to fix are reported to the owner, not filed.

See `AGENTS.md` → **Project Governance** for the authoritative rules.
