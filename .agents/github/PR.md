# Pull Request Policy — pg-api fork

This repository is a downstream modification fork of [new-api](https://github.com/QuantumNous/new-api). Changes are committed directly to `main`, and the owner decides when to push. No pull requests are opened, here or upstream.

When a change is ready:

- Commit it to `main` with a clear, factual commit message; conventional-commit prefixes are the convention in this history.
- Do not open a pull request and do not draft an upstream PR body.
- Do not reuse the upstream agent PR template that previously filled this file.
- Report the change to the owner with what changed and why, the commands actually run and the results observed, and what was not verified.

If the owner explicitly asks for a pull request, state in its body that the change was AI-generated or AI-assisted.

See `AGENTS.md` → **Project Governance** for the authoritative rules.
